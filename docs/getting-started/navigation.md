# Navigation

When a client calls mid-load-out asking whether their VL3500 Spots have left the building, you don't want to click through five menus to find out. GearFlow is built so you can jump to any asset, project, client, or warehouse view in a couple of keystrokes — the same speed you'd expect from your phone's spotlight search. The faster you move through the app, the less time at a desk and the more time on the floor.

This page covers the three ways to get around: the sidebar for browsing, global search for finding a specific thing, and the command palette for power-user jumps and actions.

## Left sidebar

The sidebar runs along the left side of the screen and gives you access to every major section. From top to bottom:

| Item | Where it takes you |
|---|---|
| **Dashboard** | Your main overview with active projects, warehouse status, and recent activity |
| **Inventory** | All equipment — assets, bulk assets, models, kits, categories |
| **Projects** | Quotes and active projects, project templates, crew assignments |
| **Clients** | Your client list and contact details |
| **Warehouse** | Deployment and returns, pull sheets, stocktakes |
| **Documents** | Generated PDFs and the template designer |
| **Crew** | Crew members, the planner, timesheets |
| **Suppliers** | Suppliers, purchase orders, sub-hires |
| **Compliance** | Test and tag, maintenance, workshop, check items |
| **Reports** | Built-in and custom reports |
| **Settings** | Organisation settings, billing, team, integrations |

Click any item to open that section. Some items expand to show sub-pages (e.g. **Inventory** expands to **Equipment**, **Kits**, **Categories**).

You can collapse the sidebar by clicking the hamburger icon at the top left, which is helpful on smaller screens.

## Global search bar

Press **Cmd+K** (Mac) or **Ctrl+K** (Windows/Linux) to open the global search. You can also click the search bar at the top of the sidebar.

Search finds results across:
- **Assets** by asset tag, serial number, or custom name
- **Models** by name, manufacturer, or model number
- **Bulk assets** by asset tag
- **Kits** by name or asset tag
- **Projects** by project number or name
- **Clients** by name or contact name
- **Suppliers** by name, account number, or contact
- **Locations** by name or address
- **Categories** by name
- **Maintenance records** by title
- **Crew members** by name, email, or department

Results appear as you type. Use the **Tab** key to drill into a section, or click a result to navigate directly.

## Command palette

The command palette is more powerful than basic search. Use it with these special prefixes:

### @ shortcuts — jump to sections

Type `@` followed by a page name to navigate directly:

| Shortcut | Destination |
|---|---|
| `@assets` | Inventory / Equipment |
| `@projects` | Projects list |
| `@warehouse` | Warehouse overview |
| `@clients` | Clients list |
| `@kits` | Kits page |
| `@crew` | Crew members |
| `@reports` | Reports |
| `@settings` | Settings |
| `@dashboard` | Dashboard |

After selecting a section, press **Space** to search within it. For example, `@warehouse` then Space then `GrandMA` searches for projects or deployments containing "GrandMA" in the warehouse view.

### / commands — actions

Type `/` to see available actions for the page you're on. For example, from the Projects page, typing `/` shows commands like:

- **New Project** — opens the create project dialog
- **Switch to Quotes** — navigates to the quotes tab
- **Generate Report** — opens a report for the current project

Available commands change depending on what page you're on and what you have permission to do.

### Date shortcuts

Type a date in `DD/MM/YYYY` format to jump directly to the availability calendar on that day.

### Keyboard tips

- **Shift+↑** / **Shift+↓** — skip between sections
- **Tab** — drill into a section's results
- **Esc** — go back one level
- **Cmd+L (Mac)** / **Ctrl+L** — toggle section children
- **↑** / **↓** — move through results

## Breadcrumbs

At the top of every page, breadcrumbs show your current location in the app. For example:

**Inventory > Equipment > VL 3500 Spot**

Click any breadcrumb segment to jump back to that level. This is especially useful when you're deep in a page — one click takes you back to the parent section.

## User menu

Click your avatar or initials in the top-right corner to open the user menu. From here you can:

- **View Profile** — see your user details
- **Account Settings** — update your name, email, password, security settings, and notification preferences
- **Sign Out** — log out of GearFlow

Your role is displayed below your name. If you're an admin, you'll also see a link to the **Admin Panel**.
