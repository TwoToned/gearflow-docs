# Documents & PDFs

GearFlow generates professional PDF documents directly from your projects — delivery dockets, quotes, invoices, return sheets, run sheets, call sheets, and timeline documents. Every document pulls real data from your project so you don't have to type it twice.

## What gets generated

| Document | Purpose |
|---|---|
| **Delivery Docket** | Equipment list with checkboxes for on-site delivery and return signing |
| **Quote / Invoice** | Financial summary with line items, totals, deposit and balance |
| **Return Sheet** | Condition tracking sheet for gear coming back from site |
| **Run Sheet** | Pre-show organisation — schedules, contacts, venue details |
| **Call Sheet** | Crew schedule with call times, roles, and contact info |
| **Timeline** | Visual overview of project dates, deployments, and returns |

## Generating a document

Open any project and click the **Documents** button in the top bar. Choose the document type from the dropdown. If you have custom templates published, you'll see them listed alongside the default template.

GearFlow builds the PDF using live project data — equipment, crew assignments, dates, and pricing — and opens it in a new tab for you to review.

## Downloading and sending

Once the PDF is generated, you can:

- **Download** — save the PDF to your device
- **Print** — print directly from the browser
- **Email** — send to the client or crew from within GearFlow (attached as a PDF)

Your company logo and branding are applied automatically based on the template configuration.

## Templates

Every document type uses a template that controls the layout, sections, and branding. See the [Template Designer](./template-designer) page to learn how to customise them.
