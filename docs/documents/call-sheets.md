# Call Sheets

A call sheet tells every crew member where they need to be and when. It shows the full crew schedule for a given day (or range of days), with call times, roles, and contact details.

## What's on a call sheet

- **Project info** — project name, venue, location, site contact
- **Crew table** — one row per crew member showing:
  - Name
  - Role
  - Phase (bump-in, event, bump-out, etc.)
  - Call time and wrap time
  - Phone number
  - Notes
- **Day headers** — when generating for multiple days, each day gets its own section with date and phase badges

Crew are sorted by call time (earliest first), then by role. Project managers appear at the top.

## Generating a call sheet

Call sheets are generated from crew assignments and their shifts.

1. Open a project
2. Click **Documents** > **Call Sheet**
3. Optionally filter by:
   - **Date** — single day call sheet
   - **Date range** — multi-day sheet with day separators
   - **Crew member** — sheet for one person
   - **All dates** — one document covering the full project

If shifts have been created from assignments, the call sheet uses shift-specific times. Otherwise it falls back to the assignment start/end times.

## Multi-day call sheets

When you select multiple dates, the PDF includes a **day header** section between each day. Each header shows the date, phase badges, and crew count so the document stays organised across a multi-day run.
