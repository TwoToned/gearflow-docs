# Timeline PDF

The timeline PDF gives a visual overview of a project's key dates — when gear is deployed, when it returns, and the phases in between. It's useful for client approvals, site inductions, or your own planning board.

## What's on the timeline

- **Project bar** — the full project duration as a horizontal bar
- **Deployment markers** — when equipment is scheduled to go to site
- **Return markers** — when equipment is scheduled to come back
- **Phase segments** — bump-in, event, bump-out periods colour-coded for readability
- **Milestones** — key dates (site visit, rehearsal, show date, etc.)

## Generating a timeline

1. Open a project
2. Click **Documents** > **Timeline**

The PDF uses the project's start and end dates along with any deployment / return schedules from the equipment list and warehouse phases.
