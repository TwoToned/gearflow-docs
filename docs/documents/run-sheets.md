# Run Sheets

A run sheet gives everyone on the project a single-page reference for the show — venue details, key contacts, schedule, and equipment overview. Use it to keep the team aligned before and during an event.

## When to use a run sheet

Run sheets are useful for:

- **Live events** — one sheet for the whole production team
- **Multi-day jobs** — a run sheet per day or per phase (bump-in, event, bump-out)
- **Handovers** — give the on-site crew a quick reference so they don't need to open the app

## What's on a run sheet

- Venue name and address
- Site contact name and phone
- Project manager and crew leads
- Schedule — bump-in, event start, bump-out times
- Equipment summary (key items, not every serial number)
- Client name and contact
- Any special notes or instructions

## Generating a run sheet

1. Open the project
2. Click **Documents** > **Run Sheet**

The document is generated from the project's current data — dates, assigned crew, equipment list, and venue information.
