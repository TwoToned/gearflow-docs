# Project Tasks

Each project has a **Tasks** tab for tracking to-do items. Tasks work like a simple Asana-style list — create tasks, assign them, track progress.

## Creating a task

1. Open a project and go to the **Tasks** tab.
2. Type a task title into the quick-add input and press **Enter**.
3. The task is created with **To do** status and **Normal** priority.

For more detail, click the task to open the edit dialog and set:

| Field | Description |
|---|---|
| **Title** | Task name |
| **Description** | Longer notes or instructions |
| **Status** | To do, In Progress, or Done |
| **Priority** | Low, Normal, or High |
| **Due date** | Optional deadline (shown in red when overdue) |
| **Assignee** | A user or crew member responsible for the task |
| **Checklist** | Sub-steps with individual checkboxes |

## Managing tasks

Tasks are grouped by status in the panel: **To do**, **In progress**, and **Done**.

Each row shows:
- Status toggle — click to cycle through To do (circle) → In Progress (dot) → Done (checkmark)
- Priority dot (colour-coded)
- Due date badge
- Checklist progress (e.g. `2/4`)
- Assignee avatar

Use the row dropdown menu to edit, advance status, or delete a task.

## Reordering

Tasks are manually ordered within a project. Drag and drop to reorder, or use the dropdown to move a task to the next status column.

## Viewing tasks across projects

Your personal tasks across all projects are available from the home screen — it shows non-Done tasks assigned to you, ordered by due date and priority.
