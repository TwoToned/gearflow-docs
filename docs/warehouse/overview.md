# Warehouse

The **Warehouse** module is where you manage the physical flow of equipment — picking gear off the shelves, packing it into containers, deploying it to a project, and checking it back in when it returns.

![Warehouse view — manage check-in, check-out, pull sheets, and displays](/img/screenshots/warehouse.png)

## Three-phase flow

Every project moves through three warehouse phases:

```
Pick / Prep → Deploy → Return
```

| Phase | What happens |
|---|---|
| **Prep** | Pick equipment off the shelf, pack it into containers, and get it ready to go |
| **Deploy** | Mark prepped gear as checked out to the project |
| **Return** | Check gear back in, record condition, flag damage or missing items |

## Warehouse tabs

Open a project's warehouse page and you'll see four tabs:

| Tab | Purpose |
|---|---|
| **Prep** | Scan or browse items to pack. Assign containers. Confirm packing. |
| **Deploy** | All prepped gear, grouped by container. Deploy all or selected items. |
| **Return** | All deployed gear, grouped by container. Check items back in with condition tracking. |
| **Bulk Check-In** | Project-wide accessory totals — check in every accessory type across the whole job with one action. |

## Projects as rows

The main warehouse view lists every active project as a row. Click into a project to see its items and work through the three phases.

## Containers

Containers let you group gear that's packed together — a road case, flight case, or ad-hoc grouping. Select a container during prep and every item you prep gets tagged with that container name. In the Deploy and Return tabs, items are grouped under their container headers so the team can see what's packed where.

## Real-time sync

Every warehouse action — prep, deploy, return — broadcasts a real-time update to everyone in your organisation. Open the same project on two screens and changes appear instantly without refreshing. See the team member who just checked in that last item without calling across the warehouse.
