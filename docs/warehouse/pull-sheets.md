# Pull Sheets

A **Pull Sheet** is a printable list of every item in a project — the paper (or PDF) your warehouse team carries while they walk the shelves and pick gear. It's the bridge between what was quoted on a project and what physically leaves the building.

When a tour load-out is staged across three aisles and you've got a casual picker who doesn't know your shelf layout, a pull sheet is what stops the truck leaving without the spare lamps. It lists every fixture, cable, and case grouped the way they'll be packed, with a checkbox against each so nothing gets missed.

![Generate a pull sheet from the warehouse Documents menu](/img/screenshots/warehouse.png)

## When to use a pull sheet

- **Packing / Prep**: Hand the pull sheet to your pickers so they know exactly what to pull from the shelves.
- **Pre-event audit**: Run through the list to confirm every item is accounted for before loading.
- **Reference on site**: Print a copy to go with the gear for the crew at the venue.

## Printing a pull sheet

1. Open the project's warehouse page.
2. Click the **Documents** dropdown in the header.
3. Select **Pull Sheet**.
4. A PDF opens in a new tab — print it from there.

## What's on a pull sheet

The pull sheet includes:

- **Project name, number, and date**
- **Client name**
- **Total item count** — every individual piece of gear, including kit children and nested grandchildren (kit parents are not counted as one)
- **Item list** grouped by container (if containers were used during prep), then by category
- Each line item shows: name, model number, quantity, and asset tag (for serialised items)
- **Checkboxes** — empty for items still to be packed, filled with a tick for items already deployed
- Kit children and nested grandchildren show their own tick/untick status based on deployment

## Using pull sheets for packing

Pull sheets show all non-cancelled items on the project. Already-deployed items display with a filled checkbox so you can see what's already been handled.

Your team can use the pull sheet alongside the Prep tab — the PDF gives a paper backup for areas where screens aren't practical.

## Related documents

The Documents dropdown also gives you access to:

- **Delivery Docket** — shows only deployed items, for the driver/crew taking gear to site
- **Return Sheet** — shows only deployed or returned items, for the check-in process
- **Quote / Invoice** — all items regardless of deployment status, for pricing reference
