# Timesheets

Timesheets track the hours your crew works — whether on a specific project or on general duties. Crew members log time, managers review and approve.

## Logging time

From a crew member's detail page, go to the **Time** tab to see all their time entries. Click **Log Time** to add a new entry.

Entries can be:

- **Project time** — linked to a specific project assignment
- **General time** — a standalone shift (e.g. "Warehouse maintenance")

Each entry records:

- Date
- Start time and end time
- Break minutes
- Description (for general entries)
- Status

Total hours are calculated automatically.

## Status flow

```
Draft → Submitted → Approved → Exported
                ↘ Disputed → Draft
```

| Status | Description |
|---|---|
| **Draft** | Entry in progress, editable |
| **Submitted** | Crew member has submitted for approval |
| **Approved** | Manager has approved |
| **Disputed** | Manager has flagged an issue; crew can edit and resubmit |
| **Exported** | Approved and exported to payroll |

## Reviewing timesheets

Managers can review timesheets from:

- **Crew** > **Timesheets** — see all entries across the organisation with filtering by date, project, and crew member
- **Dashboard** — pending timesheets shown in the stats section for quick approval

From the timesheets page you can:

- **Approve** — single or batch approve submitted entries
- **Dispute** — flag an entry with a reason; the crew member can edit and resubmit
- **Export** — download timesheets as CSV for payroll

## Crew dashboard

At **Crew**, managers see a dashboard with:

- Active crew count
- Pending timesheets
- Upcoming shifts (next 10)
- Pending offers
- Quick **Log Time** button for any crew member
- **Export** button with date range picker
