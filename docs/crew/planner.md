# Crew Planner

The crew planner gives you a 14-day Gantt-style view of every crew member's assignments and availability. See who's working, who's free, and who has conflicts — all on one screen.

## Opening the planner

Go to **Crew** > **Planner** (or click the **Planner** link under Crew in the sidebar).

The planner shows a timeline with:

- **Crew names** (sticky left column, scrolls with you)
- **Date columns** — 14 days at a time, scrollable
- **Assignment cells** — coloured blocks showing when someone is assigned to a project
- **Availability blocks** — colour-coded by type

## Colour coding

| Colour | Meaning |
|---|---|
| Primary (blue) | Active assignment |
| Red | Unavailable (hard block) |
| Amber | Tentative (soft block) or double-booked |
| Green | Preferred — wants work |

Hover over any cell for a tooltip with the project name, role, and times.

## Navigating

- **Back / Forward** arrows to move by week
- **Today** button snaps back to the current date
- Weekend columns and today's column are highlighted for easy scanning

## Assigning crew from the planner

The planner is read-only for viewing. To create or edit assignments, open the project's **Crew** tab or use the project detail page.

## Availability blocks

Crew members can set availability blocks from their detail page **Availability** tab. They're colour-coded in the planner:

- **Unavailable** — hard block, shown in red
- **Tentative** — soft block, shown in amber
- **Preferred** — wants to work, shown in green

When you assign crew to a project, conflict warnings appear if the person has overlapping availability blocks or existing assignments.
