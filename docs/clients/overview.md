# Clients

The **Clients** section lets you manage everyone you rent equipment to — from one-off event organisers to long-term corporate accounts.

## Clients list

The clients list shows all your saved clients. Each entry displays:

- **Client name**
- **Primary contact** (name and email)
- **Phone number**
- **City / location**

Click any client to open their detail page, which shows their information, linked projects, and documents.

## Adding a client

1. Go to **Clients** from the main navigation.
2. Click **+ New Client**.
3. Fill in the client details:

| Field | Description |
|---|---|
| **Client Name** | Company or individual name |
| **Contact Name** | Primary contact person |
| **Email** | Contact email address |
| **Phone** | Contact phone number |
| **Billing Address** | Street, city, postcode, country |
| **Shipping Address** | Can be different from billing address |
| **Notes** | Any internal notes |

4. Click **Create Client**.

You can also create a client on the fly when creating a new project — the **Client** field on the project form has a "Create new" option.

## Editing a client

1. Open the client from the clients list.
2. Click **Edit**.
3. Update the fields and click **Save**.

## Client addresses

Each client can have a billing address and a separate shipping address. These are used on quotes, invoices, and delivery documentation.

## Importing clients

1. Go to **Clients** and click **Import**.
2. Download the CSV template.
3. Fill in your client data using the template format.
4. Upload the completed CSV file.

The import matches on email address — existing clients are updated, new ones are created.

## Clients in projects

When you create a project and select a client, the client's details (name, contact, addresses) flow through to:

- Quotes and invoices
- Delivery dockets and return sheets
- Service addresses (for deliveries and pickups)
- Documents and reports

Updating a client's details updates them on all future documents. Existing documents keep the client details as they were when generated.
